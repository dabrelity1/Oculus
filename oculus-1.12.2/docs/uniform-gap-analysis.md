# Uniform And Sampler Audit Notes

Last updated: 2026-05-19.

This document replaces an older gap-analysis snapshot that no longer matched the current tree. It should be treated as an audit guide, not a proof of parity.

## Current Uniform Entry Points

- `ProgramBuilder` and `ProgramUniforms` own registration and upload plumbing.
- `CapturedRenderingState` stores render-frame state needed by multiple uniform groups.
- `CameraPositionTracker` handles precision camera position state.
- `CelestialUniforms`, `GameplayUniforms`, `WorldInfoUniforms`, `CompatibilityUniforms`, `IdMapUniforms`, `ShadowUniforms`, `SpecialEffectUniforms`, and `SystemTimeUniforms` provide grouped built-ins.
- `CustomUniformExpressionManager` handles `uniform.*` and `variable.*` expressions with the vendored `kroppeb.stareval` evaluator.
- `CenterDepthSampler` drives the transformed `iris_centerDepthSmooth` sampler for postprocess shader sources that declare legacy `uniform float centerDepthSmooth;`.

## Current Sampler And Image Entry Points

- `ProgramSamplers` registers built-in and custom sampler bindings, preserves the active texture unit across updates/clears, allocates dynamic sampler units within `SamplerLimits`, skips program-reserved texture units, and attaches dynamic samplers to the current program after active uniform discovery. `ProgramBuilder` passes the 1.16.5 composite/final reserved unit set `{1, 2}` for postprocess programs.
- `TextureBindingRegistry` and `TextureBinding` own texture-unit assignment.
- `CustomTextureManager` handles shader-pack texture directives, generated fallback `noisetex`, and global custom textures.
- `IrisImages`, `ProgramImages`, `ImageHolder`, and `CustomImageManager` handle image uniforms and render-target/shadow image bindings.
- `RenderTargets`, `DepthTexture`, and `ShadowMap` own runtime textures exposed to shaders.

## Audit Checklist Against 1.16.5

Use `../Oculus-1.16.5/src/main/java/net/coderbot/iris/uniforms` as the primary reference. For each uniform or sampler:

1. Confirm it exists under the same public shader name.
2. Confirm its type matches GLSL expectations.
3. Confirm the value source is updated at the correct frame/pass time.
4. Confirm previous-frame values are latched before mutation.
5. Confirm dimension/world/player null states are handled safely.
6. Confirm texture units do not collide with custom textures, shadow samplers, image units, or compute passes, and do not exceed `GL_MAX_TEXTURE_IMAGE_UNITS`.
7. Confirm behavior in a real shader pack, not only by static source inspection.

## Custom Expression Smooth-ID Semantics

Current state:

- `smooth(id, value, ...)` parses the documented optional integer ID form.

- This matches independent behavior for documented unique-ID uses.

Future agents should treat exact duplicate-ID collision behavior as unresolved. Do not replace the current per-node state with keyed global state from memory.
