# Backport Status

Last updated: 2026-05-19.

This document is the current status map for the Forge 1.12.2 Oculus backport. It is not a completion certificate. It records what exists, what is wired, and where evidence is still missing.

## Overall State

The port has moved beyond a stub foundation. It has real shader-pack discovery, preprocessing, option/profile/menu parsing, program and compute source discovery, render targets, post-processing passes, shadow rendering, custom textures/images, SSBO setup, custom uniforms, and multiple render-loop mixins.

The port is still not production-grade. The main remaining risk is runtime parity: compile/build success does not prove shader visual correctness, GL state restoration under all passes, or behavior across popular packs.
