This document tracks the current Forge 1.12.2 Relictium/Sodium integration points. Source and bytecode remain authoritative.

## Local Reference

- `/home/daniel/.gradle/caches/minecraft/deobfedDeps/deobf/maven/modrinth/relictium/1.2.0/relictium-1.2.0.jar`

`src/test/java/net/oculus/compat/relictium/RelictiumTerrainBridgeBytecodeTest.java` now pins the bytecode contracts used by the active terrain bridge. Run it after changing Relictium mixins or upgrading Relictium; it checks the `renderLayer` begin redirect target, the backend `render(...)` call wrapped for exceptional scope cleanup, the later backend `end()` call that closes terrain scope on the normal path, `ChunkRenderShaderBackend.begin()` active-program swap point, constructor/create/end/delete descriptors, chunk program/pass APIs, missing geometry enum, base chunk binding point fields, and the `ChunkRenderManager` / `SodiumWorldRenderer` fields and call sites used by the shadow visibility graph swap layer.

`src/test/java/net/oculus/pipeline/shadow/ShadowRendererBytecodeTest.java` pins vanilla 1.12 assumptions that matter to Relictium and non-Relictium shadow terrain: `ShadowRenderer.renderShadows(...)` must call `RenderGlobal.setDisplayListEntitiesDirty()` before shadow `setupTerrain(...)`, and it must keep a second dirty mark after shadow rendering. The same test also verifies that the installed 1.12 `RenderGlobal` bytecode has the `displayListEntitiesDirty` and `renderInfos` fields, that the setter writes the dirty flag, that `setupTerrain(...)` reads/updates the flag and stores rebuilt `renderInfos`, that shadow target preparation restores `OpenGlHelper.defaultTexUnit` before framebuffer work, and that the shadow pass restores the legacy depth state it mutates. The local 1.16.5 reference calls `LevelRenderer.needsUpdate()` before shadow setup for the same reason and restores `GL_TEXTURE0` before shadow target preparation. `src/test/java/net/oculus/pipeline/shadow/ShadowMapBytecodeTest.java` pins narrower GL-state invariants for the same shadow pass: the no-translucents depth copy must save and restore the caller's active `GL_TEXTURE_2D` binding after `glCopyTexSubImage2D`, and shadow mipmap generation must use a dedicated texture unit with active/bound texture restoration so later render phases do not inherit an unbound or shadow-bound texture unit from the 1.12 fallback paths.
